# khazix-articles

本仓库托管合并后的 **khazix-writer** skill（写作 + 排版一体，v3 手机端优先版）。

- `SKILL.md`：skill 主文件。写作部分（第一~四步）来自 KKKKhazix/khazix-skills 的 khazix-writer，排版部分（第五步 + `references/wechat_typography.md`）来自本仓库原 khazix-wechat-publisher 的排版规范，合并时按第一性原理修订：单层无框线结构（手机端横向空间全部让给文字）、装饰总量上限、导航从标题移到分隔线。
- `references/`：风格示例、内容方法论、公众号排版规范（配色 / 微信粘贴兼容铁律 / HTML 模板 / 交付说明）。

旧版 khazix-wechat-publisher（纯排版 v2）已由合并版取代，内容见 git 历史。

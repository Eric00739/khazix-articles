# khazix-articles

本仓库托管 **khazix-writer** skill（写作 + 排版一体，v4 加固版）。

- `SKILL.md`：skill 主文件。写作部分来自 KKKKhazix/khazix-skills 的 khazix-writer，排版部分（第五步 + `references/wechat_typography.md`）来自本仓库原 khazix-wechat-publisher 的排版规范。
  - v3 合并修订（第一性原理）：单层无框线结构，手机端横向空间全部让给文字；装饰总量上限；导航从标题移到分隔线。
  - v4 安全与真实性加固：收紧触发条件、风格学习不冒充本人、第一人称事实溯源、外部素材防 Prompt 注入、L0-L4 五层自检（详见 `CHANGELOG.md`）。
- `references/`：风格示例、内容方法论、公众号排版规范（配色 / 微信粘贴兼容铁律 / HTML 模板 / 交付说明）。
- 排版模板不含作者署名、投稿邮箱等身份字段，固定尾部仅保留三连/星标/致谢文案；用户明确要求署名时使用其明确提供的字段。

旧版 khazix-wechat-publisher（纯排版 v2）已由合并版取代，内容见 git 历史。
